## TagNote 0.1.0 – first release

TagNote is a Word-style HTML editor and viewer, and a sister program to [MarkNote](https://github.com/Cphmartinus/marknote). Your documents stay plain `.html` files.

- **Code and page side by side.** HTML with colour highlighting on the left, the live page on the right. Switch to code only or page only, and preview at 1280, 768 or 390 px.
- **Edit in the page.** Click an element to select it and type directly in the page. The change is written back to the code. Click in the code, and the matching element is highlighted in the page.
- **Safe by default.** The page runs in an isolated frame and its scripts do not run. Turn JavaScript on per file, or choose *Known* to allow only Bootstrap, Tailwind and other known libraries.
- **Style panel.** Colours, text, spacing, borders and layout for the selected element.
- **Framework tabs.** When TagNote finds Bootstrap, Tailwind CSS, Bulma or Pico in the page, extra tabs appear with components, class pickers and breakpoints.
- **Effects.** Scroll animations, hover transitions, animations, gradients, shadows, glass, scroll snap, sticky elements and a reading progress bar, all as plain CSS.
- **Design tools.** Colour palette, fluid sizes with `clamp()`, CSS variables, font pairs and a page check that finds missing alt texts, titles and duplicate ids.
- **Export** to PDF, clean HTML, Markdown (for MarkNote) and plain text.

The interface is complete in Danish and English. In the other 11 languages, texts that are new in TagNote are shown in English.

### Downloads

- `TagNote-Setup-0.1.0.exe`: installer. **Recommended.** Later versions can be installed from *Help → Search for updates*.
- `TagNote-0.1.0-portable.exe`: runs without installation. It unpacks itself on every start, so it starts more slowly.

The files are not code-signed, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

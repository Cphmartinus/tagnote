## TagNote 0.2.0 – make a website without knowing code

TagNote now starts in **Simple** mode, made for people who have never written HTML. The code and the technical tools are hidden, and everything uses plain words. Everything from 0.1.0 is still there under **Advanced**, one click away in the status bar.

- **Start from a ready-made page:** New lets you choose an empty page, a personal page, a café or shop, a club or a portfolio.
- **Type in the page as in Word.** Click something, and a small toolbar appears: bold, italic, size, colour, alignment, move, copy and delete. Double-click a picture to change it.
- **Insert** headings, text, lists, pictures, videos, buttons, links, columns, cards, tables and dividers, placed just below what you clicked.
- **Design the whole page** with colour themes, fonts, space, corners and page width. **Look** changes just the part you selected.
- **Effects** such as slide in on scroll are applied to the part you selected, without any code.
- **Save as a website:** the first save creates a folder with `index.html`, and pictures are copied into it automatically, so they always work.
- **Check the page** explains problems in plain language and fixes many of them with one click.
- **Help on the spot:** a short tour on first start, a **?** on every ribbon group, and friendly names such as Button and Heading instead of HTML tags.

Fixes: changes in the code are no longer overwritten when you save or format right after typing, keystrokes are no longer lost while the page redraws, pictures no longer overflow small screens, AltGr characters such as `{ [ ] }` always type, and Ctrl+/ comments code on Nordic keyboards.

The new interface texts are in Danish and English. In the other 11 languages they are shown in English for now.

### Downloads

- `TagNote-Setup-0.2.0.exe`: installer. **Recommended.** Install it over 0.1.0; your settings are kept. TagNote 0.1.0 can also get this update from *Help → Search for updates*.
- `TagNote-0.2.0-portable.exe`: runs without installation. It unpacks itself on every start, so it starts more slowly.

The files are not code-signed, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.
